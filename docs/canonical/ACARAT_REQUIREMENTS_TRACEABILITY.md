## Traceability rule

A requirement cannot be removed because an implementation task omitted it.

Changes require:

1. explicit requirement disposition;
2. owning document update;
3. roadmap/SpecGrain update;
4. reason and evidence;
5. founder decision when scope materially changes.

Deferred means still owned, not forgotten.
